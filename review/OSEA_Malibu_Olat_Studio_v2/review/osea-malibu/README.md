# OSEA Malibu Outreach Package

Olat Studio standard outreach package for a public-source Japan market-entry review.

## Files

- `index.html` — English snapshot for outreach
- `ja.html` — Japanese review version
- `research.md` — internal research notes with source URLs
- `email.txt` — initial outreach email
- `followup.txt` — follow-up email
- `README.md` — package notes and update history

## Version

- Version: 2.0
- Updated: July 18, 2026
- Status: Ready for review and publishing

## Design and content changes in v2

- Replaced numerical opportunity scores with qualitative assessments.
- Reduced text and improved scanability.
- Added a language switch between English and Japanese versions.
- Rewrote the executive summary around one clear recommendation.
- Simplified the roadmap to three practical steps.
- Kept facts, evidence, assessments, and recommendations distinct.
- Removed unsupported statements about demand, sales, and market size.
- Kept source names only in the public HTML pages; URLs remain in `research.md`.
- Used the standard USD $29 Business Opportunity Report CTA only in the Next Step section of the snapshot.

## Publishing

For GitHub Pages, publish the repository root or the relevant project folder and use:

- English: `review/osea-malibu/index.html`
- Japanese: `review/osea-malibu/ja.html`

Replace `{{SnapshotURL}}`, `{{FirstName}}`, and `{{YourName}}` in the email files before sending.
